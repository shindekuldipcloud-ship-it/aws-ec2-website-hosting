# AWS EC2 Static Website Hosting

## Project Overview
This is a beginner DevOps portfolio project to learn how to host a static website using AWS EC2, Ubuntu, and Nginx.

## Technologies Used
- AWS EC2
- Ubuntu Linux
- Nginx
- HTML and CSS
- Git and GitHub

## Project Goals
- Understand Git version control.
- Create and manage a project repository on GitHub.
- Learn how a web server hosts a static website.
- Practice basic Linux and DevOps commands.
